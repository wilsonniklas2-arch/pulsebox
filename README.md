# Vision

PulseBox ist eine intelligente Social-Music-Plattform für Gastronomie, Bars, Restaurants, Hotels, Clubs, Eventlocations und öffentliche Veranstaltungsorte.

Im Gegensatz zu einer klassischen Jukebox entscheidet nicht eine einzelne Person über die Musik.

Stattdessen können alle Gäste gemeinsam in Echtzeit abstimmen, welche Musik als Nächstes gespielt wird.

Dadurch entsteht ein interaktives Musikerlebnis, das Gäste aktiv einbindet und die Atmosphäre verbessert.

---

# Problem

In vielen Bars und Restaurants gibt es heute nur zwei Möglichkeiten:

• Eine feste Playlist läuft.

oder

• Eine Person entscheidet über die Musik.

Beides berücksichtigt die Stimmung der Gäste nur eingeschränkt.

Es gibt derzeit kaum Lösungen, die eine faire, einfache und professionelle Mitbestimmung der Musik ermöglichen.

---

# Unsere Lösung

PulseBox verbindet einen Musikdienst (z. B. Spotify) mit einer intelligenten Voting-Plattform.

Jeder Gast kann:

- aktuellen Song sehen
- Songs suchen
- Songs vorschlagen
- für Songs abstimmen
- Warteschlange verfolgen

Das System entscheidet automatisch anhand der abgegebenen Stimmen, welcher Song als Nächstes gespielt wird.

Wenn niemand abstimmt, läuft automatisch eine definierte Hintergrundplaylist weiter.
